# Marquee-Dev

A personal web development practice repository containing HTML, CSS, JavaScript, and small frontend project examples.

## Repository Overview

This folder is organized into learning exercises and project demos for frontend web development.

- `CSS/` — layouts and styling practice using boxes, flexbox, grid, media queries, and positioning.
- `HTML/` — HTML exercises grouped by day, including forms, tables, menus, and simple page layouts.
- `JS/` — JavaScript examples for variables, scope, operations, loops, functions, strings, arrays, objects, and interactive page scripts.
- `Projects/` — small web UI projects and clones for learning page structure, layout, and responsive design.
- `Merquee-MERN.md` — written notes covering JavaScript fundamentals, data types, type conversion, operators, functions, and arrays.

## Folder Details

### CSS
- `Boxes/` — basic box-based layout examples.
- `Day 8/` — styling and model practice.
- `Day7/` — flexbox and layout practice.
- `Flex/` — flexbox-specific examples.
- `FlexBox/` — additional flexbox demonstration pages.
- `Grid/`, `Grid-Test/`, `Grid_test2/` — CSS Grid layout experiments.
- `media_2/` — media query practice for responsive design.
- `Medit/` — styling practice pages.
- `postion/` — CSS positioning examples.

### HTML
- `Day1/` — basic HTML pages and a simple form.
- `Day2/` — movie-themed page examples.
- `Day3/` — menu and content layout practice.
- `Day4/` — additional form practice.
- `Day5/` — job and table layout pages.
- `Day6/` — Amazon-style product page and resume page examples.

### JS
- `operations/` — scripts demonstrating array operations, BMI calculator, math calculations, loops, objects, and string handling.
- `variables/` — variable scope and basic script examples.

### Projects
- `Book_my_show/` — event or ticket booking page UI practice.
- `Flex_assignment/` — flexbox assignment page.
- `Flipkart/` — ecommerce landing page clone.
- `Menu/` — menu-style interface or navigation practice.
- `Profile_Card/` — profile card UI design.
- `Restaurant/` — restaurant webpage layout practice.
- `Youtube/` — video platform interface practice.

## How to Use

Open any HTML file in a browser to view the page.

For JavaScript examples, open the corresponding HTML file in `JS/variables/` or run the `.js` files in a browser-connected environment.

## Notes

This repository is intended for learning and experimentation with frontend web technologies. Each folder contains standalone examples that can be opened directly in the browser.
